### **Comandos Básicos do Spec Kit**


## 🛠️ **Solução de Problemas**

### **Dashboard Web Não Carrega Completamente**

- **Status**: Servidor online, interface com problemas de JavaScript
- **Solução**: Use os relatórios HTML alternativos em `http://localhost:8080/`
- **Comando**: `pkill -f spec-workflow-mcp && npx -y @pimzino/spec-workflow-mcp@latest ...`

### **Rate Limit na Porta 3000**

- **Status**: ✅ Resolvido - Servidor Next.js funcionando normalmente
