# 👥 Gestão de Usuários (v3)

Visão geral das funcionalidades de convites, papéis e perfis de usuário por empresa.

## Conceitos
- Convites por e-mail com role e company predefinidos
- Aceitação, criação/associação de conta ao tenant
- Edição de perfil, status ativo/inativo

## APIs Relacionadas
- `app/api/users` (CRUD)
- `app/api/invitations` (convites)

## Tabelas
- users, invitations, user_roles
