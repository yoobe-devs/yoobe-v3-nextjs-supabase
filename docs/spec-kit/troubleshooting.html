🚨 Problemas Conhecidos

Dashboard Web com Problemas

A interface web principal (localhost:3456) está apresentando problemas de carregamento e pode retornar erro 404.

Soluções:

  • • Use a documentação HTML como alternativa (localhost:8080)
  • • Reinicie o servidor MCP: pkill -f spec-workflow-mcp
  • • Verifique se a porta 3456 está livre
  • • Acesse a API REST diretamente: localhost:3456/api/specs

Servidor HTTP Parado

O servidor HTTP para documentação HTML pode parar de funcionar, impedindo o acesso às páginas.

Soluções:

  • • Reinicie o servidor: cd docs && python3 -m http.server 8080
  • • Verifique se a porta 8080 está livre
  • • Use a documentação integrada: /docs/spec-kit

🔍 Guia de Diagnóstico

1. Verificar Status dos Serviços

# Verificar processos MCP
ps aux | grep spec-workflow-mcp

# Verificar portas em uso
lsof -i :3456
lsof -i :8080

# Testar conectividade
curl http://localhost:3456/api/specs
curl http://localhost:8080/spec-kit/index.html

2. Reiniciar Serviços

# Parar processo MCP
pkill -f spec-workflow-mcp

# Reiniciar Spec Kit
npx -y @pimzino/spec-workflow-mcp@latest /Users/genautech/Downloads/v3-main/yoobe-v3 --AutoStartDashboard --port 3456

# Reiniciar servidor HTTP
cd docs && python3 -m http.server 8080

3. Verificar Logs

# Verificar logs do sistema
tail -f /var/log/system.log | grep spec

# Verificar logs do processo
ps aux | grep spec-workflow-mcp

# Verificar uso de memória
top -p $(pgrep spec-workflow-mcp)
