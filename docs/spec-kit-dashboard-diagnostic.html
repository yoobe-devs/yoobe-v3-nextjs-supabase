✅ Soluções para Dashboard Completo

  1. Verificar no Navegador:

    Acesse http://localhost:3456 e verifique se há erros no console do navegador (F12)

  2. Limpar Cache do Navegador:
    # No navegador, pressione Ctrl+Shift+R (ou Cmd+Shift+R no Mac)
    # Ou acesse: http://localhost:3456/?v=1
  3. Verificar JavaScript:
    # Testar se o JS está carregando:
    curl -s http://localhost:3456/assets/index-DMhIadFO.js | head -5
  4. Reiniciar Servidor:
    pkill -f spec-workflow-mcp
    sleep 3
    npx -y @pimzino/spec-workflow-mcp@latest /Users/genautech/Downloads/v3-main/yoobe-v3 --AutoStartDashboard --port 3456
