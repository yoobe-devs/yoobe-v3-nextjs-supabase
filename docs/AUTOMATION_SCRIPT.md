# ⚡ Script de Automação de Documentação (v3)

Este documento descreve como utilizar o script de geração de documentação de telas.

## Arquivo
- `scripts/generate-screen-docs.js`

## Objetivo
- Varre as telas (rotas/app) e gera arquivos Markdown padronizados em `docs/screens/`.

## Execução (exemplo)
```bash
node scripts/generate-screen-docs.js
```

## Saída
- Arquivos `.md` por tela com seções: Identificação, Campos, Integrações, Fluxo, Screenshot.
